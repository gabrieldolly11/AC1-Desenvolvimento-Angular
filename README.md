# AC1 - Catálogo de Filmes

Desenvolvimento Web Front-End - Facens.

## Integrantes

## Projeto

Catálogo em Angular para adicionar e selecionar filmes, marcar favoritos e registrar visualizações.

## Executar

Com o Node.js 24 instalado, execute na pasta do projeto:

```bash
npm install
npm start
```

Acesse http://localhost:4200.
